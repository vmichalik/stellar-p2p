Check an existing transfer response

This authenticated diagnostic checks HTTP status and JSON structure for one existing outgoing Revolut-to-Revolut transfer. It creates no payment and cannot authorize settlement.

Verifier:

The approved disclosure is the transfer request path (including its transaction ID), HTTP status, Content-Type, the JSON root marker and selected field names. Cookie and authorization values, payment amounts, recipient values and other financial values are not selected for disclosure.

After opening the extension, navigate to the existing transfer and use Check response only. Review the extension's disclosure prompt before approving it.
