Check a Revolut payment

Choose an existing outgoing Revolut-to-Revolut transfer to test its payment proof. This check does not move money.

The extension will ask to share a proof with the verifier shown below. It includes the transfer’s amount, currency, recipient code, transaction ID, status, completion time and type, plus the request path, HTTP status and response date. Review the disclosure and approve it only if you trust the verifier operator.

A valid proof authenticates Revolut’s response. The payment still needs to match an escrow order before funds can be released. The contract trusts the configured verifier’s signing key.
